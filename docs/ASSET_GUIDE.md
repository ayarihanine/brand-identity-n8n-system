# Asset Guide

The `brand/` directory contains the complete Freshy Matcha visual reference package. The files are organized by role so the identity can be reviewed, presented, or reused without guessing which asset belongs where.

| Asset | Format | Recommended use |
| --- | --- | --- |
| `FreshyMatcha-logo.png` | PNG | Primary logo reference and brand-mark close-up. |
| `brand1.png` | PNG | Light identity application board covering packaging and touchpoints. |
| `brand2.png` | PNG | Dark premium application board for contrast-led presentation. |
| `brandstory.png` | PNG | Light brand-story composition for editorial storytelling. |
| `brandstory2.png` | PNG | Hero cover and primary case-study visual. |
| `colorPalette.png` | PNG | Approved color system and natural-material references. |
| `typography.png` | PNG | Playfair Display and Montserrat pairing reference. |
| `Freshy_Matcha_advertisement_design_202608291218.mp4` | MP4 | Original commercial film with full-quality playback and audio. |
| `Freshy_Matcha_advertisement_preview.gif` | GIF | Lightweight motion preview for Markdown and GitHub surfaces. |

## Usage principles

Keep the logo on clean, high-contrast backgrounds and preserve its proportions. Use the cream and green palette as a system rather than as isolated decorative colors. Pair editorial headlines with clear supporting copy, and maintain the visual themes of natural light, tactile materials, leaves, matcha powder, ceramic, stone, and bamboo.

For presentations, use `brandstory2.png` as the opening visual, place the identity boards before the system references, and introduce the commercial after the static identity has been established. Use the MP4 for native video platforms and the GIF only as an inline preview or fallback.
